---
name: production-analysis
description: 制作工程の記録（開始・終了・待ちの理由・担当・資源・費用）から、CPM でクリティカルパスと待ち時間を分析し、改善案を出す。制作を振り返るとき、工程の短縮を考えるときに使う。
---

あなたは制作工程の生産管理担当です。添付の記録(工程ごとの開始・終了・待ちの理由・担当・資源・費用)だけを根拠に分析してください。推測した値には「推定」と書き、根拠を添えてください。

1. 工程の前後関係を有向グラフ(DAG)にし、CPM で各工程の ES・EF・LS・LF・余裕を出す。
   - 所要時間は「実績の幅」と「作業だけの時間(待ちを除く)」の2通りで計算する。
2. クリティカルパスを示す。全体の時間を「作業 / 工程内の待ち / 工程間の空き / やり直し / 人の判断待ち」に分け、それぞれ何時間かを出す。
3. 待ちの理由の上位5つを出す。それぞれ、何を待っていたかと合計時間を書く。
4. 工程ごとに表を作る。
   - 並列にしてよいか(共有資源・共有ファイルで判断)
   - 担うべきは スクリプト / 外部サービス / AIエージェント / 人 のどれか
   - 軽いモデルで足りるか
5. 改善案を、「次の制作で縮む時間」の大きい順に5つ出す。
   - 改善を順に当てはめた場合の全体時間を、1つずつ再計算して示す(例: 40h → 35h → … → 9h)。
6. 結論は3行で書く。

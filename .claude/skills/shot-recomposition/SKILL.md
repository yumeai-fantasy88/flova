# shot-recomposition(構図の点検と作り直し)

## 呼び出されるとき

「日の丸っぽい」「横並びで舞台みたい」「構図を直して」と言われたとき。量産した絵や開始フレームの点検にも使えます。

## 手順

1. **点検:** カットごとにチェックリストで採点し、4つの判定に分けます。
   - 判定: 採用 / 部分修正 / 背景ごと作り直し / 新しいアングルを足す
   - チェックリストの中身:
     - 見せたいことを1行で言えるか
     - 顔が画面中央の縦帯にないか
     - 横一列・目の高さ・正面になっていないか
     - 力関係(アオリ/俯瞰)と向き(左→右/右→左)が台本と合っているか
     - 前景・逆光・動く要素があるか
     - 前後のカットと同じ構図が続いていないか
2. **設計:** カメラ設計表を作り、上から見たブロッキング図も描きます。
   - 設計表の項目: 見せたいこと、視点、高さ、寄り、三分割のどこに置くか、前景、光、動く要素、前後との並び
   - ブロッキング図: 人物・カメラ・画角を間取りに描いたもの。生成の参照画像にもします。
3. **指示文:** 決まった順番の型に当てはめて書きます。「日の丸・正面・平らな光を避ける」英語の禁止文を必ず入れます。
4. **生成:** 共通の待ち行列で回します(fal の GPT Image 2.5 を主に、Codex を予備に)。1カットにつき2案ずつ作り、一覧画像にします。
   - FLOVA の企画（映像素材は100% FLOVA）では、画像も FLOVA の画像生成で作る。
5. **確認:** 作り直した絵を手順1のチェックリストで点検し直し、Before/After の動画(CAM_before_after.mp4 と同じもの)を作って、人の承認を1回で取ります。
